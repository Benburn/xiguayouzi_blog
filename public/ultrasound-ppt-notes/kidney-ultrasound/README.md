# 肾脏超声 · 全面知识精讲（HTML PPT）

## 使用方式

直接用浏览器打开 `index.html` 即可演示，无需构建或联网（字体走 CDN，可离线降级）。

目录内另附 `预览截图/`（每页一张 1920×1080 PNG），方便不打开网页快速浏览整体效果。

页面内所有图片均可**点击放大**（弹出大图 + 图注），点击任意位置或按 `Esc` 关闭。

键盘操作：

- `←` / `→` / `Space`：翻页
- `T`：切换主题（academic-paper / minimal-white / corporate-clean / editorial-serif / swiss-grid）
- `O`：页面概览
- `S`：演讲备注（逐页 speaker notes）
- `F`：全屏
- `N`：快速备注抽屉
